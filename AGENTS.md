# Project writing preferences

Never use em dashes (Unicode U+2014) in authored content, including app text,
documentation, GitHub descriptions, release notes, and assistant replies.
Use clear sentences with periods, commas, colons, parentheses, or normal hyphens.
Use N/A or Not reported for unavailable values. Never substitute zero for missing data.

Keep release documentation accurate: distinguish published downloads from changes
still under development, and never describe unverified account switching as tested.
