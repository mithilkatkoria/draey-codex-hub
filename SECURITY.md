# Security

This is an early test build that handles local Codex authentication. No security audit is claimed.

Do not include tokens, auth.json, account backups, personal emails, or raw account responses in issues. For a sensitive vulnerability, use GitHub's private vulnerability reporting on this repository when available; do not post exploit details or credentials publicly. General non-sensitive bugs can be filed as issues.

Only share the clean release assets. Authentication backups under local application data are sensitive and are not configuration exports.
